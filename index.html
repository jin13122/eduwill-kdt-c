Training Goals

과정 훈련목표

기초부터 실무까지, 6개월 완주 후 도달하는 명확한 목표입니다.

01

개발 기본기 확립

컴퓨팅 사고력과 Python 기초 문법, 객체지향 프로그래밍 핵심을 탄탄히 다져 완주합니다.

02

관계형 데이터베이스(RDB) 역량

MySQL 설계(ERD), 정규화, 복합 SQL 쿼리를 자유자재로 다루는 실무 역량을 배양합니다.

03

현업 표준 개발 환경 경험

Git 브랜치 협업 전략, API 서버 구축 및 클라우드 배포 과정을 직접 수행합니다.

04

생성형 AI 실무 도구 융합

OpenAI API, LangChain, Pinecone을 활용해 실제 동작하는 AI 서비스를 완성합니다.

05

기업 과제 기반 실전 포트폴리오

실제 기업 프로젝트를 수행하여 서류 전형과 기술 면접에서 강력한 경쟁력을 입증합니다.

Curriculum

체계적인 6단계 교육과정

기초부터 프로젝트 포트폴리오까지 순서대로 정복합니다.

STAGE 01

프로그래밍 기초 및 개발 환경

• Python 핵심 문법, 데이터 구조 및 알고리즘 기초
• Git/GitHub 형상관리, VS Code 가상환경 셋업
STAGE 02

프론트엔드 웹 개발

• HTML5 / CSS3 / Modern JavaScript 반응형 웹 설계
• React 기반 Single Page Application(SPA) 및 Axios 비동기 통신
STAGE 03

백엔드 & RDB 데이터베이스

• MySQL 데이터베이스 모델링, 테이블 정규화 및 심화 SQL 작성
• Flask / Node.js 기반 RESTful API 구축 및 JWT 인증 구현
CORE AI

생성형 AI 실무 응용

• OpenAI API 연동 챗봇 및 인텔리전트 서비스 구축
• LangChain, LlamaIndex 기반 프롬프트 엔지니어링
• Pinecone 벡터DB 연동을 통한 RAG(검색 증강 생성) 시스템 실습
STAGE 05

실무 프로젝트 & 포트폴리오

• 기업 과제 기반 팀 프로젝트 수행 (기획 - 설계 - 개발 - 클라우드 배포)
• Notion 기술 문서화, 시연 발표 및 GitHub 포트폴리오 완성
STAGE 06

취업 역량 강화 및 매칭

• 코딩 테스트 대비 알고리즘 및 CS 기본기 코칭
• 1:1 맞춤 이력서/포트폴리오 첨삭, 실전 모의면접, 우수 기업 매칭
